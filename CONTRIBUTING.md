# Contributing

Thanks for helping improve OTP Message Extractor.

1. Open an issue describing the message format or false positive.
2. Create a focused branch.
3. Add or update a test in `test/extract-otp.test.js`.
4. Run `npm run check`.
5. Open a pull request explaining the behavior change.

Never include a real phone number, real OTP, or other private data in issues and tests. Use invented examples only.
